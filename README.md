# German Word Play 📚

**German Word Play** (Reading Helper) is a dedicated Android mobile application designed to assist readers, support language learners, and enhance text accessibility. Built natively with modern Android standards using Kotlin and Jetpack Compose.

---

## ✨ Features
*   **Reading Assistance:** Visual formatting aids designed to improve text readability and focus.
*   **Accessibility First:** Designed with straightforward navigation, making it ideal for educational purposes or supportive learning.
*   **Modern Android Architecture:** Crafted using up-to-date developmental frameworks ensuring fluid, lightweight device performance.

## 🛠️ Tech Stack
*   **Language:** Kotlin
*   **Build System:** Gradle (Kotlin DSL - `build.gradle.kts`)
*   **Platform:** Android

---

## 🚀 Getting Started

### Prerequisites
*   Android Studio (Latest stable version recommended)
*   JDK 17 or higher
*   Android SDK

### Installation & Local Setup

1. Clone the repository to your local machine:
   ```bash
  git clone https://github.com/surangakula/LeseHelfer.git
   ```

2. Open the project folder in **Android Studio**.
3. Let Gradle sync and resolve all dependencies automatically.
4. Connect an Android Emulator or a physical device with USB debugging enabled.
5. Click the **Run** button (`Shift + F10`) inside Android Studio to build and launch the app.
